## Giới thiệu

Bài thực hành gồm ba Lab về JavaScript cơ bản, thao tác DOM và
sử dụng jQuery. Trang chủ giới thiệu nội dung đã học và liên kết
đến từng bài thực hành.

## Cấu trúc thư mục

- `index.html`: Trang chủ JavaScript Labs.
- `css/`: File định dạng giao diện trang chủ.
- `images/`: Ảnh đại diện.
- `Lab08/`: Các bài thực hành JavaScript cơ bản.
- `Lab09/`: Các bài thực hành DOM và sự kiện.
- `Lab10/`: Các bài thực hành jQuery.

## Nội dung thực hành

- **Lab 08:** Biến, mảng, hàm, đối tượng và Console.
- **Lab 09:** DOM, sự kiện, biểu mẫu và gỡ lỗi.
- **Lab 10:** jQuery selectors, sự kiện, hiệu ứng và GET request.

## Cách truy cập

Mở file `index.html` bằng trình duyệt, sau đó chọn Lab và bài
thực hành muốn xem. Một số bài cần kết nối Internet để tải
tài nguyên hoặc dữ liệu từ dịch vụ bên ngoài.
