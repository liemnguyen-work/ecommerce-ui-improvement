# Bài tập CSS tuần 3

Nguyễn Thanh Liêm · MSSV 31241023460 · Phát triển ứng dụng Thương mại điện tử

Mở `index.html` để vào trang cá nhân và các bài. Bài 3 chọn nhánh làm bài 4–7. Bài 8 chọn css2. Bài 9 dùng Font Awesome Free 6.7.2 với font được lưu cùng mã nguồn.

Ảnh trong `minh-chung/css-diner/` và `minh-chung/css-speedrun/` lấy từ lượt chạy minh họa do Codex thực hiện trên game gốc. `minh-chung/game-results.json` ghi selector và trạng thái được game xác nhận. `BaiTap1.html` dẫn đến từng ảnh và hai game để sinh viên tự luyện.

Các trang HTML và CSS được dựng theo đề. Thư mục Drive của bạn cùng lớp được xem để đối chiếu cách tổ chức và minh chứng. Các ảnh nhân vật thuộc tệp css2 do giảng viên cung cấp. Các nguồn ảnh và thư viện được liệt kê dưới đây.
