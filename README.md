# Bài tập cá nhân Buổi 2 HTML5 và CSS3

## Giới thiệu

Bản mẫu thời trang Mặc tiếp tục mã nguồn và repository Buổi 1. Website tham khảo: https://www.uniqlo.com/vn/vi/. Trọng tâm là danh sách bốn sản phẩm. Hình SVG, tên và giá là dữ liệu học tập, không phải website hoặc giá bán hiện tại của UNIQLO.

## Chạy website

Mở index.html sau khi giải nén, giữ css/ và images/ cùng cấp. Đã kiểm tra mở trực tiếp bằng file:// trong Chromium; CSS và ảnh dùng tệp cục bộ. Không cần thư viện hoặc kết nối mạng để tải giao diện.

## Kỹ thuật và thay đổi

- HTML5 có ngữ nghĩa, ảnh có alt, menu và kích cỡ dùng ul/li.
- CSS riêng; element, class và descendant selector; margin, padding, border, border-radius và border-box.
- Flexbox cho menu/nhóm kích cỡ và nội dung thẻ; Grid 4/2/1 cột tại các mốc 1024px và 600px.
- Details/summary mở mô tả bằng HTML gốc; liên kết mở ảnh SVG có thật.
- Hover, transition 0,2 giây, focus-visible và hỗ trợ giảm chuyển động.
- Cỡ chữ phụ được tăng; dòng Tiết kiệm hiện 15px ở quy tắc cơ sở và 16px dưới 600px.
